# Privacy Policy

Kruti Dev Converter does not collect, store, transmit, or share any personal data or user information.

All text conversion between Kruti Dev and Unicode Hindi is performed locally within your browser. No text, browsing activity, or webpage data is sent to any external server.

The extension only accesses the active webpage and selected text when required to perform the requested conversion.

Permissions used:

* `contextMenus` — to provide right-click conversion options.
* `activeTab` — to access selected text on the current webpage for conversion.

No analytics, tracking, advertisements, or remote code are used in this extension.
